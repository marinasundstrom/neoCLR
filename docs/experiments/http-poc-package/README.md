were built in release mode from a clean managed worktree; the bridge/reference and

links/special or escaping entries, and compare every regular file with its staged
SHA-256 before extraction. All 440 SDK and 1,063 runtime-bundle files matched;

## Limits and release disposition

This closes package acceptance for the bounded HTTP POC on this host. It does not
validate an editor package, other binary targets, load behavior or a complete release.
The source/runtime remains a bounded HTTP/1.1 experiment: cleartext, fixed deadlines,
1,024-byte buffered responses/server bodies and up to 65,536-byte known-length client
uploads. Source reads are synchronous; no TLS, pooling, response streaming or HTTP/2/3.

Known compiler observations and the unexplained earlier timeout remain in the owning
trackers; these successful serial runs do not declare them repaired. Release work
still requires the selected candidate's hosted CI, supported binary packages/editor
workflow and explicit known-defect disposition. The SDK dependency audit found
YamlDotNet 16.3.0 missing from the old attribution inventory; its upstream MIT notice
is added to the companion attribution set before distribution. The source-archive audit also identified socket2 and ten Windows support crates
missing from the older Rust inventory. Their checksum-verified crate notices are
added. Existing archives remain unchanged and must be accompanied by the updated
attribution archive; the selected release should package these notices directly.
