# System namespaces

neoCLR's library uses `System` namespaces for platform types. These are neoCLR
contracts, not a claim that the .NET base class library is available unchanged.

The initial generated reference covers [System.Tasks](xref:System.Tasks). The
[API overview](/docs/index.html) links the current feature guides for arrays,
collections, text, outcomes, files, time and introspection. Documentation coverage
will expand as those APIs develop.
