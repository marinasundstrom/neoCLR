## Culture and formatting

Culture and Language describe supported profiles. DateTimeFormat combines a culture
with calendar-aware date/time formatting, while fixed and system culture providers
make the source of that choice explicit.

See [globalization](/features/globalization/) for the implemented profiles and
formatting limits. Time values, calendars and time-zone mappings live in System.Time;
this module does not imply the full .NET culture catalog.
