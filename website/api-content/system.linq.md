## Queries over collections

Operators provides filtering, projection and terminal operations over iterable
collections. Optional results and cardinality failures use explicit outcomes,
including SingleError where a query requires exactly one result.

See [collections and queries](/features/collections/) for the supported query
surface. Follow each operator's documentation for evaluation behavior and generic
limitations; this module does not promise every .NET LINQ operator.
