## TCP connections and listeners

Socket supports the current IPv4 TCP operations: connecting, listening, accepting,
sending, receiving, inspecting the local port and closing. SocketError reports
expected transport failures.

See [sockets](/docs/sockets.html) for bounds, deadlines and resource lifetime.
System.Web.Http layers its bounded HTTP protocol support over this transport.
