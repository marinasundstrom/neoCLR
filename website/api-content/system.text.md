## Text building and encoding

StringBuilder accumulates text and produces immutable String snapshots.
UnicodeScalar and Utf8 provide scalar and strict UTF-8 operations. Encoding,
Encoder and Decoder describe the supported conversion contracts, with Encodings
providing the implemented encodings.

See [strings and UTF-8](/features/strings/) and [streams](/docs/streams.html).
String itself lives in System. Byte limits, malformed-input handling and encoder
completion are explicit parts of individual APIs.
