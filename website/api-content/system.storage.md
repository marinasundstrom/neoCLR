## Paths, items and providers

Path describes storage addresses. StorageItem, File and Directory represent stored
resources, and StorageProvider separates lookup from the host FileSystem provider.
Opened byte and text streams use System.IO contracts.

Start with [storage items](/docs/storage-items.html),
[providers](/docs/storage-provider.html) or the [working example](/docs/storage-poc.html).
FileText and Metadata are submodules for host-path text and kind lookup.
