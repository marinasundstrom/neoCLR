## Construction and member access

Extension operations add supported construction, invocation, field and property
access to introspection descriptors. ReflectionError reports validation and
capability failures through Result.

See [reflection](/docs/reflection.html) for the supported shapes and execution-mode
limits. Retained metadata does not guarantee that every described member can be
invoked, particularly in the experimental native backend.
