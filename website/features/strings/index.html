Strings and UTF-8.
A small working start.

The current implementation can convert String values to UTF-8 bytes and decode them again. This is a starting point for trying the behavior and discussing the API.

Next-preview work · September 19, 2026. This page records the current implementation, not a settled design. Names, signatures and behavior may change as we learn from use and feedback. A matching development toolchain is required.

CURRENT IMPLEMENTATION

Round-trip valid Unicode.

Utf8.Encode(text) returns Sequence<byte>, with Count, indexed access and iteration. Utf8.Decode(bytes) accepts that same collection interface and returns Result<string, InvalidUtf8Error>.

{{UTF8_ROUNDTRIP}}

Use patterns to extract a successful value or its error. For example, RoundTrip("café 🌍") prints Round trip. Malformed UTF-8 produces an error instead of replacement text. Conversion currently copies bytes; it is not a zero-copy API.

SMALL SCOPE

Where we’re heading.

The immediate aim is a small usable String API. Possible follow-ups include scalar iteration, grapheme-aware operations and UTF-16 interchange. Char and ordinal comparison retain their current behavior; specialized string types and an Encoding hierarchy are deferred.

.NET offers configurable UTF-8 decoding, including a strict mode. This implementation starts with a strict Result and Sequence-based byte access. Whether those are the right long-term contracts is open for feedback.
