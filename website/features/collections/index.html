IMPLEMENTATION NOTE · OPEN DESIGN

Ask for the access you need.

Sequence provides count and indexed read access. MutableSequence adds replacement; List adds growth. Arrays and lists can be consumed through these capabilities.

Preview 8 implementation · September 19, 2026. This is a bounded implementation, not a complete or frozen API. Use the matching Preview 8 packages. These APIs remain open to feedback.

Behavior and limits.

The roles are comparable to .NET collection interfaces, with replacement separated from growth. More precise contracts help describe what an algorithm requires, at the cost of more interface distinctions. Where and Select are lazy; ToList materializes, First/Last return Option and Single returns Result.

Where we’re heading.

Variance, immutable or frozen providers, and broader query coverage need separate decisions. The aim is useful collection contracts, not reproducing every .NET collection type. Iterator and mutation behavior should stay explicit.
