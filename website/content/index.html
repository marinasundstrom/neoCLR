Runtime, library and tools

The runtime executes compiled Raven programs with automatic memory management. The class library is organized into modules that form namespaces. The toolchain includes a compiler, project support and a VS Code extension.

Programs run in the interpreter. An ARM64 ahead-of-time compiler also produces standalone executables for a supported subset of applications.

How neoCLR fits together →

Try the project

The downloadable macOS arm64 bundle includes the tools and runnable collections, Tasks, JSON and HTTP samples. Start with a bundled project, then explore the library.

neoCLR is experimental and APIs can change. It has its own runtime and libraries; it does not run arbitrary .NET applications. Native compilation has narrower coverage than the interpreter.
