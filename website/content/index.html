Docs can lead the release

This site tracks development. Preview 9 is the published baseline described by the installation guide; some documented APIs require a newer development toolchain.

A website publication does not announce a runtime release. Check each page’s availability notes and use the matching sample and toolchain.

Build toward useful applications

The active milestone is a small HTTP client/server pair. Work proceeds through byte, text, JSON, storage and delayed-operation samples before networking.

General sockets, HTTP and a JIT are not released capabilities. The importer supports a bounded CLI subset, not arbitrary unchanged .NET assemblies.
