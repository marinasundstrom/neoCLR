Try the native Raven POC

Preview 12 brings native Raven metadata import and emission, source-built library consumers, Tasks, JSON and HTTP examples, and VS Code API help. The matched native toolchain is qualified on macOS arm64; primitive bootstrap and runtime seed dependencies remain explicit.

The platform is experimental. Feature pages explain current limits and possible directions; use the matching runtime and development tools.

Install the matching toolchain →

Build toward useful applications

The development milestone is end-to-end Raven compilation into native NeoCLR assemblies. Nine of ten selected POC samples compile and execute, including collections, JSON mapping, async work and a localhost HTTP pair. Inheritance and the native editor workflow remain release gates.

HTTP is a bounded cleartext POC; TLS, HTTP/2, HTTP/3 and a JIT remain future work. The importer supports a bounded CLI subset, not arbitrary unchanged .NET assemblies.
